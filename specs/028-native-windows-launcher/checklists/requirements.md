# Requirements Checklist: Native Windows Launcher

- [x] User stories are independently testable and prioritized.
- [x] Clean-machine operation does not assume Docker, Python, or .NET.
- [x] Broker terminal, xtquant, account data, and credentials remain external.
- [x] Explicit path precedence and ambiguous discovery behavior are defined.
- [x] Interactive QMT login is separated from MCP process liveness/readiness.
- [x] Loopback, token protection, redaction, and no-admin defaults are defined.
- [x] Windows Service, credential automation, trading, and remote exposure are
  explicitly out of scope.
- [x] Mac development, Windows CI, clean-VM, and real-QMT verification are
  separated.
- [x] ZIP, installer, versioning, checksum, and existing Release compatibility
  requirements are measurable.
- [x] Constitution principles are checked with no unrecorded exceptions.
